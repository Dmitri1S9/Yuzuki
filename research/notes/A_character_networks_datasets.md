### What carries over to Fandom wiki text
- Wiki text is already a third-person summary, so the **summary-based** work is the closest match (Massey's SparkNotes, Srivastava's Wikipedia plots, LiSCU). Novel-oriented tooling targets problems we mostly don't have: coref over 100k tokens, quote attribution, co-occurrence networks.
- **Hallucinated names.** Three works point the same way. Conan finds that errors in character extraction cap relation quality, that a **gold character list helps**, and that pairwise prompting **raises hallucinations**. CHIRON filters claims with entailment. CREFT demands evidence for every step. For us: build the candidate set from **hyperlinks / `[[...]]` targets in the paragraph** (wikitext gives near-free entity linking), constrain the LLM to choose from that list, require an evidence quote, and drop any output whose name or quote is not a substring of the paragraph.
- **Label set.** Massey's taxonomy plus affinity is the most reusable, at about 30 labels collapsible to about 12. DialogRE's `matching_table.txt` is already a Fandom-to-label map. Conan's 5 top-level classes make a good GNN target: Romantic / Family / Ally / Adversarial / Business.
- Abstract traits (machiavellianism) failed because the text never states them. Get trait labels from crowd data (Section 2) instead of LLM judgement, or have the LLM pick concrete bipolar adjectives with evidence.
- Joint, triad-aware inference (Srivastava 2016) is effectively what a GNN does. Use it as justification for the design.

## Verdict: what I'd use for this project
1. **Relations:** parse Fandom infobox kin / master / apprentice / affiliation fields as high-precision silver edges. Use them to score the LLM extractor and as GNN training labels. Spot-check with Wikidata P26 / P3373 / P7047 for Star Wars and Western universes.
2. **Extraction prompt:** restrict candidates to the `[[links]]` in each paragraph, use a closed Massey-style label set (or Conan's 5 top-level classes), require an evidence span, and reject outputs whose name or evidence is not found verbatim (the CHIRON/Conan lessons).
3. **Traits:** stop asking the LLM for abstract constructs. Use **SWCPQ, 2,125 characters × 500 bipolar adjectives (CC BY-NC-SA)** as gold for the overlapping ~100+ characters, and have the LLM rate those same concrete adjective pairs.
4. **Taxonomy reference:** reuse DialogRE's `matching_table.txt` (Fandom relation words to labels) to collapse free-text relation words.
5. **Skip** BookNLP, RMN, PDB scraping and Kaggle MBTI. They are built for novels or have poor validity, so they don't fit encyclopedic wiki text.
